
# 🎓 ITACE Plantel Reynosa
## Página Web Informativa Institucional

### 1. Nombre del proyecto

**ITACE Digital – Plantel Reynosa**

Proyecto escolar de desarrollo web enfocado en la creación de un sitio informativo sobre el ITACE Plantel Reynosa, Tamaulipas.

---

### 2. Descripción

Este proyecto consiste en el desarrollo de una página web informativa que permite conocer diferentes aspectos del ITACE Plantel Reynosa.

El sitio reúne información sobre la institución, su historia, oferta educativa, actividades estudiantiles, instalaciones y otras secciones de interés para la comunidad escolar.

La página busca ofrecer una experiencia visual atractiva, organizada y adaptable a distintos dispositivos.

**Nota:** Este sitio es un proyecto escolar informativo no oficial.

---

### 3. Objetivo

**Objetivo general:**

Diseñar y desarrollar un sitio web informativo, atractivo y funcional que facilite el acceso a información relacionada con el ITACE Plantel Reynosa.

**Objetivos específicos:**

- Organizar la información mediante distintas páginas y secciones.
- Implementar un menú de navegación adaptable a dispositivos móviles.
- Utilizar HTML para estructurar el contenido.
- Aplicar CSS para crear una presentación visual atractiva.
- Incorporar JavaScript para añadir interactividad.
- Facilitar la consulta de información institucional.
- Aplicar los conocimientos adquiridos durante el desarrollo del proyecto escolar.

---

### 4. Tecnologías utilizadas

**HTML5**
- Estructura y organización del contenido.
- Creación de páginas, enlaces, imágenes y secciones.

**CSS3**
- Diseño visual del sitio.
- Colores, tipografías, tarjetas y animaciones.
- Adaptación a diferentes tamaños de pantalla.

**JavaScript**
- Menú de navegación responsivo.
- Carruseles interactivos.
- Ventanas informativas.
- Galerías y controles de navegación.
- Filtros de contenido.

**Visual Studio Code**
- Editor utilizado para desarrollar y organizar el código.

**Git y GitHub**
- Control de versiones.
- Almacenamiento y administración del código fuente.

### 6. Funcionalidades

El proyecto contempla las siguientes funcionalidades:

- Navegación entre páginas mediante un menú principal.
- Menú hamburguesa para dispositivos móviles.
- Diseño adaptable a computadoras y celulares.
- Presentación de la historia institucional.
- Carrusel de carreras.
- Ventanas con información de las carreras.
- Presentación de clubes y actividades estudiantiles.
- Galería fotográfica interactiva.
- Secciones informativas de instalaciones y admisiones.
- Apartados de noticias, proyectos y eventos.
- Filtros de categorías para futuras publicaciones.
- Botón para regresar al inicio de la página.

Algunas secciones están preparadas para incorporar información oficial posteriormente.

---

### 7. Instrucciones para ejecutar el sitio

**Opción 1: Desde la computadora**

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Localizar el archivo `index.html`.
4. Hacer doble clic sobre él.
5. Visualizar la página en un navegador como Google Chrome.

**Opción 2: Desde Visual Studio Code**

1. Abrir Visual Studio Code.
2. Seleccionar **Archivo → Abrir carpeta**.
3. Abrir la carpeta del proyecto.
4. Localizar `index.html`.
5. Abrir el archivo en el navegador.

El sitio está desarrollado principalmente con HTML, CSS y JavaScript, por lo que no requiere instalar dependencias para visualizar sus páginas estáticas.
